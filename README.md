# Sparrow's Stat per WA Calculator

A buildless MapleLegends calculator for stat/WA ratios, gear upgrades, Maple Warrior and temporary WA buffs.

## Run locally

Serve the dist directory with any static web server.

## Vercel

Import this GitHub repository, select the Other framework preset, leave the build command empty and set the output directory to dist. No dependencies, environment variables or install command are required.

Manual totals are pre-MW and pre-WA-buff. MW uses user-supplied AP-only base stats; upgrade changes represent equipment stats. MW30 is configured as 13%.

Formula source: Nise's Formula Compilation on MapleLegends forums. Monster defense, critical hits, caps and special effects are excluded.
